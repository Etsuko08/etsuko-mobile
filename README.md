# Etsuko Mobile — Neural Audio Studio

Cyberpunk touch-first mobile music streaming client & Progressive Web App (PWA).

## Features
- **OLED Dark Mode & Cyber Aesthetics:** Ambient glowing accents, 60fps glassmorphism.
- **Ergonomic Bottom Nav & Floating Mini-Player:** Tap or swipe up to reveal full-screen now-playing sheet.
- **MediaSession Lockscreen Integration:** High-res album artwork and control center buttons on iOS & Android.
- **Synced Karaoke Lyrics:** Auto-scrolling synchronized lyrics.
- **PWA Ready:** Installable directly to home screen via Safari & Chrome.
